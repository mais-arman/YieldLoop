# 3. Make offcut-rate presentation consistent

The backend already calculates offcut rate correctly in reports. Reuse the authoritative backend calculations instead of introducing a competing formula.

Implement:

- An explicit offcut rate on each job card when issued weight is valid.
- An explicit offcut rate for each side of the comparison.
- The offcut-rate difference in percentage points in the comparison, using the same left-minus-right convention as the existing comparison.
- Clear handling of missing values and zero denominators.
- Consistent labels and precision across job details, reports, and comparison.

Use these definitions:

- Good yield = good output / issued material × 100.
- Scrap rate = total scrap / issued material × 100.
- Offcut rate = reusable offcuts / issued material × 100.

Reusable offcuts must never be included in scrap.

Do not duplicate calculations unnecessarily in the frontend. Do not change correct existing calculations or the current Decimal-based accounting.

For the reference cases, the expected results are:

- IK-202 offcut rate: 5%.
- IK-203 offcut rate: 8%.
