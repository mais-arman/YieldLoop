---
name: Shared role experience
description: Product requirement for common navigation and presentation across the three YieldLoop roles
---

Cutting Operator, Production Supervisor and Manager must use the same shell,
common-page structure, navigation order and visual design. Employees is the only
role-specific navigation addition and is Manager-only. Do not create separate
role dashboards or restore the Overview role-description showcase.

**Why:** The user explicitly requested a shared application experience rather
than role-specific presentation.

**How to apply:** Keep common navigation ordered Dashboard, Production Jobs,
Cutting Studio, Inventory, Reports. Preserve existing backend-enforced action
permissions: shared presentation never grants new write authority.
